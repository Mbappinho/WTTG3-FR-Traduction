WTTG3 - Traduction francaise (pack Nexus drop-in)
=================================================

COMPATIBILITE STEAM (v1.6.1)
- Jeu : Welcome to the Game III (Steam officiel)
- AppID : 3869850
- BuildID Steam cible : 24415407
- Verifie ton BuildID : steamapps\appmanifest_3869850.acf (ligne "buildid")
  S'il differe du BuildID ci-dessus → risque de crash ; attends une
  release FR a jour.
- steam_target.json (racine du zip) = version du pack + BuildID cible
- PAS d'auto-update dans ce zip Nexus (pas de .bat/.ps1)
  Pour maj auto : pack GitHub Full → WTTG3-FR-Traduction.zip + INSTALLER.bat
  https://github.com/Mbappinho/WTTG3-FR-Traduction/releases

CONTENU (aucun .bat / .ps1 — regles Nexus)
- Mod UI FR : WTTGSD\Content\Paks\WTTGSD-Windows_FR_P.*
- PDF in-game FR : WTTGSD\Content\RawFiles\PDFS\...
- Option AZERTY (desactivee par defaut) : dossier optionnel_azerty\
  (voir LIREMOI_AZERTY.txt dedans) — pak ZQSD seulement, pas d'injecteur
- PAS de fichiers anglais d'origine redistribues

------------------------------------------------
INSTALLER (premiere fois — drop-in)
------------------------------------------------
1. Ferme le jeu completement.
2. Steam > clic droit sur le jeu > Gerer > Parcourir les fichiers locaux
   (= dossier qui contient WTTGSD)
3. Dezippe CE pack DANS ce dossier (fusionne avec WTTGSD existant).
4. Relance le jeu.

------------------------------------------------
OPTION AZERTY (ZQSD) — optionnel
------------------------------------------------
Par defaut le drop-in N'ACTIVE PAS le remap clavier.
Pour avancer avec Z / gauche avec Q (Windows reste en AZERTY) :
1. Copie WTTGSD-Windows_FR_AZERTY_P.* depuis optionnel_azerty\
   vers WTTGSD\Content\Paks\
2. Relance le jeu
Desactiver : supprime ces 3 fichiers FR_AZERTY_P.* dans Paks.

MINI-JEUX DE HACK (MemDealloc, ShiftSEQ, etc.) :
  Le jeu lit toujours W/A/S/D. Avec le pak AZERTY :
  → utilise les touches W/A (positions QWERTY) pour ces hacks,
  → OU ne copie pas le pak pour garder WASD partout.
  Pas d'injecteur (retire — fatal errors).

Si tu avais installe le Full v1.6.0 avec injecteur et le jeu crash :
  supprime / renomme WTTGSD\Binaries\Win64\dwmapi.dll
  et les fichiers WTTG3-Menu* / AutoHotkey64.exe a la racine du jeu,
  ou utilise le pack Full v1.6.1+ (INSTALLER nettoie tout seul).

------------------------------------------------
METTRE A JOUR (proprement — Nexus)
------------------------------------------------
1. Ferme le jeu.
2. Telecharge la derniere WTTG3-FR-Traduction-Nexus.zip
3. Verifie steam_target.json : BuildID = ton jeu
4. Re-dezippe par-dessus le meme dossier jeu
5. Relance le jeu

------------------------------------------------
DESINSTALLER
------------------------------------------------
1. Ferme le jeu.
2. Supprime FR_P.* (+ FR_AZERTY_P.* si present) dans WTTGSD\Content\Paks\
3. Remettre les PDF EN : Steam > Verifier l'integrite

------------------------------------------------
SI LE JEU CRASH AU LANCEMENT
------------------------------------------------
1. Desinstalle (ci-dessus) + retire dwmapi.dll s'il reste un vieux 1.6.0
2. Verifie que le jeu sans mod demarre
3. Installe la derniere release FR compatible
